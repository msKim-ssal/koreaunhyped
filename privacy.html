Privacy Policy: Korea Unhyped Uploader

Last updated: October 27, 2026

Korea Unhyped Uploader is an internal tool used only by the owner of the Korea Unhyped YouTube channel. It is not offered to the public and has no other users.

What it accesses

Through YouTube API Services, the tool signs in to the channel owner's own Google account with OAuth and uses it only to upload the channel's own videos, set their thumbnails and add their captions. It requests the scopes youtube.upload and youtube.force-ssl.

What it stores

The tool stores one OAuth refresh token on the owner's computer and in the owner's private cloud environment, so uploads can run without signing in again. It does not collect, sell or share any personal data, and it does not read data about other YouTube users.

Revoking access

Access can be revoked at any time from the Google Account security page: myaccount.google.com/permissions. Deleting the stored token removes all data the tool keeps.

Google and YouTube

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Contact

Questions: the contact email listed on the Korea Unhyped YouTube channel's About page.
